year filters, and provides source excerpts behind generated answers.

`Python` · `RAG` · `ChromaDB` · `BM25` · `Anthropic API`

`Python` · `FastAPI` · `Next.js` · `TypeScript` · `PostgreSQL` · `Gemini API`
